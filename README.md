# Scientific Calculator Dashboard

Static site, no build step. Installable PWA that works offline.

## Deploy
- **GitHub Pages:** push these files to a repo, then Settings > Pages > Deploy from branch > `main` / root.
- **Netlify / Vercel / Cloudflare Pages:** import the repo (or drag the folder). No build command; publish directory is the root.

Service workers need HTTPS (or localhost); all of the above provide it.
